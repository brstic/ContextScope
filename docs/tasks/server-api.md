# Task: apps/server/src/api (+ apps/server/test/api*.test.ts)

First read docs/tasks/server-common.md and follow it. The dashboard (apps/web, already built against this contract) uses the DTOs in packages/shared/src/api.ts. Read apps/web/src/lib/api.ts to match exact params/behaviour.

Deliver `apps/server/src/api/`:
- `live.ts`: `createLiveHub(opts?: { maxBuffered?: number }): LiveHub` — subscribers get events; a slow subscriber whose buffer exceeds maxBuffered (default 1000) is dropped. `registerEvents(app, deps)` → GET /api/events as SSE: headers text/event-stream, no-cache, X-Accel-Buffering no; `retry: 3000`; heartbeat comment/event every 15 s (`event: heartbeat`); each LiveEvent written as `event: <type>\ndata: <json>\n\n`; respects backpressure (skip/queue bounded); cleans up on close. Auth: when auth is enabled accept `?token=` here too (EventSource can't send headers).
- `security.ts`: `registerSecurity(app, { config })`: when config.authToken set (required by startup when host is not loopback), every /api/* request needs `authorization: Bearer <token>` (or `?token=` only for /api/events), compare with crypto.timingSafeEqual; 401 JSON otherwise. CSRF: all non-GET /api/* need header `x-contextscope-csrf: 1` and, if an Origin header is present, it must match the Host (same-origin) → else 403. CORS: none (no Access-Control-Allow-Origin headers at all). Security headers on dashboard + API responses: X-Content-Type-Options nosniff, Referrer-Policy no-referrer, X-Frame-Options DENY, a CSP for the dashboard (default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; connect-src 'self'). Errors: a Fastify error handler for /api returning `{error:{code,message,ref}}` with no stack traces; 5xx messages generic + ref id logged.
- `routes.ts`: `registerApi(app, ctx: ServerContext)`. Validate query/body with zod (400 `{error:{code:'invalid_request',message}}`). All analytics aggregate in SQL (better-sqlite3 prepared statements via ctx.store.sqlite are fine and preferred for aggregates; do not load whole history in memory). Pagination: page ≥1, pageSize 1..200 (default 50). Endpoints and DTOs exactly per packages/shared/src/api.ts:
