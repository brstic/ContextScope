# Task: apps/server/src/proxy (+ apps/server/test/proxy*.test.ts)

First read docs/tasks/server-common.md and follow it.

Deliver `apps/server/src/proxy/`:
- `routes.ts`: `buildRoutes(config): Route[]` from validated config only (openai → /openai, anthropic → /anthropic, gemini → /gemini, customProviders → /<name> with protocol adapter 'openai'). Upstream origins only from config. `resolveRoute(routes, url)` → {route, restPath, query} or null. Rewriting is explicit: `/openai/v1/chat/completions?x` → `${upstream}/v1/chat/completions?x`; `/anthropic/v1/messages` → `${upstream}/v1/messages`; `/gemini/v1beta/models/m:streamGenerateContent?alt=sse&key=..` → `${upstream}/v1beta/models/...` (query preserved byte-for-byte for forwarding, redacted only for storage). Reject path traversal / encoded traversal (`..`, `%2e%2e`, `//`, backslash) with 400, never resolve against a different host. Never accept a per-request upstream (no Host/X-Forwarded-Host/absolute-URI influence; absolute-form request targets rejected).
- `proxy.ts`: `registerProxy(app: FastifyInstance, deps: { routes: Route[]; pipeline: Pipeline; config: ContextScopeConfig; logger }): void`. Use Fastify only for routing: register catch-all for each route prefix with all methods, and a content-type parser that does NOT parse (`app.addContentTypeParser('*', ...)` scoped to the proxy plugin so /api keeps JSON parsing) — stream `request.raw` straight to upstream with undici `request()` / `dispatcher.dispatch` (body = the IncomingMessage stream, duplex half), keep-alive Agent (`new Agent({ connect: { timeout: connectTimeoutMs }, headersTimeout, bodyTimeout: idleTimeoutMs })`), TLS verification ON. Then `reply.hijack()` and write status + headers to `reply.raw` yourself, piping the upstream body with backpressure (respect `write()` false → wait for 'drain'; or stream.pipeline). Bytes to the client must be IDENTICAL to upstream (no re-encoding: request upstream with the client's accept-encoding as-is and pass content-encoding through; for analysis, if content-encoding is gzip/br/deflate/zstd, decompress a COPY in the side channel with node:zlib, bounded).
- Header handling: drop hop-by-hop headers (connection, keep-alive, proxy-*, te, trailer, transfer-encoding, upgrade, host) and the ContextScope integration headers (x-contextscope-session/project/trace: read them first) before forwarding; set host for the upstream; keep everything else (auth headers must be forwarded to upstream unchanged — just never logged/stored). Response: drop hop-by-hop, keep the rest including content-length when present.
- Side channel observer (`observer.ts`): tee each response chunk into a bounded observer that never blocks: SSE (`text/event-stream`) → providers' SseParser → adapter.createStreamAccumulator(match); Gemini streamGenerateContent without alt=sse (JSON) → JsonArrayStreamParser feeding the same accumulator with {event:null,data:JSON.stringify(obj),id:null,retry:null}; record ttftMs when the first event with meaningfulOutput arrives (not heartbeats). Non-stream JSON: keep bounded copy in responseBody for the pipeline. Request body: bounded copy (maxInspectBytes) collected while streaming upstream. If the observer throws, catch, log (redacted) and stop observing — the client stream continues.
- Timing: performance.now() based: connectMs if measurable (else null), ttfbMs at upstream response headers, ttftMs, durationMs at end. 
- Abort/cancel: client disconnect (reply.raw 'close' before finish / request aborted) → abort upstream via AbortController, state 'client_aborted'. Upstream error / timeout before headers → respond 502 (connect/DNS) or 504 (timeout) with JSON `{"error":{"type":"contextscope_upstream_error","message":...}}` (redacted message, no stack) and header `x-contextscope-error: 1`; after headers were sent → destroy client socket, state 'upstream_error'. Upstream HTTP errors (4xx/5xx) are forwarded verbatim (state 'completed').
- Limits: request bodies above limits.maxRequestBytes → 413 (count bytes while streaming; abort). No automatic retries. Never modify request or response bodies.
- Unknown path under a valid prefix: still proxied (GET /openai/v1/models works), match=null → pipeline stores metadata only. Paths outside any prefix are not the proxy's business (Fastify 404 / dashboard).
- Notify `pipeline.notifyStarted` at start (with model unknown → null is fine) and `pipeline.submit(exchange)` once at the end (exactly once, even on abort/error), with a CapturedExchange per types.ts (redactedPath via core redactUrl, responseHeaders via redactHeaders).
- Session id: header x-contextscope-session (≤256 chars, printable) else null. Project: x-contextscope-project else 'default'.
